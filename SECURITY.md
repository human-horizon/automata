# Security Policy

Please do not report vulnerabilities in public issues, discussions, or pull requests.

If the repository's GitHub Security tab offers **Report a vulnerability**, use that private reporting flow. If it is unavailable, ask a repository maintainer privately for a reporting channel before sharing technical details. Do not include exploit details in a public request.

No dedicated security contact is currently published in this repository. Please do not infer or use a personal contact address from commit history.
