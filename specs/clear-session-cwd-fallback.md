# Исправление Clear при изменившемся рабочем каталоге сессии

## Контекст

Кнопка `Clear` останавливает текущий эмулятор, удаляет JSONL-историю сессии и запускает сессию заново с тем же идентификатором. Для `AI#2` отображаемое имя безопасно преобразуется в идентификатор `ai-2`, поэтому символ `#` не попадает в идентификатор и не является непосредственной причиной сбоя.

Файл сессии `humanhorizon__human-horizon.automata.ai-2` был создан с каталогом `/Users/a/Space`, а текущий эмулятор находился в `/Users/a/Space/Projects/HumanHorizon/automata`. Поиск JSONL выполняется только в каталоге, вычисленном из текущего рабочего каталога. Поэтому файл истории не находится и не удаляется.

## Цель

Сделать `Clear` устойчивым к изменению рабочего каталога после создания сессии: история очищается, а элемент сессии в дереве остаётся и перезапускается с тем же идентификатором.

## Что изменится

1. `internal/paths/sessionfile.go` — поиск JSONL сначала в каталоге текущего `cwd`, затем резервный поиск по каталогам хранилища сессий.
2. `internal/paths/sessionfile_test.go` — регрессионные тесты для имени `AI#2`, преобразованного идентификатора `ai-2`, и несовпадающего текущего `cwd`.
3. `internal/ui/chat_panel.go` — корректный расчёт экранной ширины Unicode-кнопки `× Clear`.
4. `internal/ui/chat_panel_test.go` — существующая проверка точной ширины строки кнопки.
5. `CONTEXT.md` — запись о причинах ошибок и решениях.

## Детали реализации

1. Сохранить приоритет точного поиска в каталоге, соответствующем переданному `cwd`.
2. Если в нём нет сессии, просканировать остальные непосредственные каталоги внутри каждого корня `SessionRoots`.
3. Сопоставлять сессию по полю `id` первой JSON-строки, декодируя JSON вместо поиска подстроки.
4. При нескольких совпадениях выбирать наиболее новый файл по времени изменения.
5. Не удалять элемент дерева, настройки или данные `ai-knowledge`; удаляется только JSONL-история just-pi.
6. Рассчитывать ширину `× Clear` в экранных ячейках, а не в байтах UTF-8.
7. После удаления запускать существующий сценарий перезапуска без изменения идентификатора сессии.

## Критерии приёмки

- [x] `Clear` находит и удаляет JSONL сессии `humanhorizon__human-horizon.automata.ai-2`, даже если текущий `cwd` отличается от каталога создания файла.
- [x] Сессия `AI#2` остаётся в дереве и перезапускается с тем же идентификатором.
- [x] Для совпадающего `cwd` сохраняется существующее поведение.
- [x] Сессии с похожими идентификаторами не удаляются.
- [x] Строка с кнопкой `× Clear` занимает ровно заданную ширину терминала.
- [ ] Целевые и полные тесты проходят.
- [x] `go vet ./...` не сообщает ошибок.
- [x] `go build -o automata .` завершается успешно.
