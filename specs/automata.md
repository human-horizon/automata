# Automata — TUI AI-агент

## Контекст

Automata — терминальный AI-агент, который работает в warp-окружении.
Старт — дерево чатов/папок, управляемое мышкой.

## Цель

Создать базовую структуру Automata: warp (layout) + tree (виджет дерева с папками и чатами).

## Дерево — API

```go
// Item — элемент дерева: папка или чат
type Item struct {
    Name     string
    IsFolder bool
    Children []*Item
    Expanded bool       // Папка развёрнута
    ID       string     // Уникальный ID
}

// Tree — виджет, реализует warp.Panel
type Tree struct {
    root     []*Item    // Плоский список корневых элементов
    selected int         // Индекс в flat-списке видимых элементов
    scroll   int         // Скролл видимых элементов
}

func New() *Tree
func (t *Tree) AddFolder(name string) *Tree
func (t *Tree) AddChat(name string) *Tree
func (t *Tree) Folder(name string) *Item  // Найти корневую папку по имени
```

## Рендеринг

- Каждый видимый элемент — одна строка
- Отступ = уровень вложенности × 2
- 📁/📄 иконки
- Выбранная строка подсвечена
- Работает скролл (колесо мыши, если элементов больше чем места)

## Управление

- **Левый клик** на 📁 — свернуть/развернуть
- **Левый клик** на чат — выбрать (фокус на item)
- **Левый клик** в пустой области — меню создания в корне
- **Правый клик** — контекстное меню
- **Колесо мыши** — скролл
- **Клавиатура:** ↑↓ навигация, Enter — развернуть/свернуть/открыть чат
- **a/c** — создать папку/чат внутри выбранной папки
- **F6** — вернуть фокус из терминала в дерево
- **Ctrl+F** — создать папку (в корне)
- **d** — удалить выбранный элемент (с подтверждением)
- **Drag modal** — перетаскивать модальное окно за заголовок/содержимое мышью
- **Mouse click on buttons** — клик по кнопкам `[Del]` / `[Esc]` в модальном окне подтверждения удаления
