# Удаление действия папки

## Контекст

Folder Actions можно регистрировать через `add_action` и запускать из KnowledgePanel, но удалить сохранённую запись нельзя.

## Цель

Добавить `remove_action({name})`, который сразу удаляет указанную Action текущего folder-domain без диалога подтверждения.

## Что изменится

1. `just/pi/extensions/automata/index.ts` — Pi tool удаления по имени в текущем domain.
2. `just/pi/extensions/automata/index.test.mjs` — тесты удаления, валидации и изоляции.
3. `CONTEXT.md` — контракт и проверки.

Go UI, reader и storage layout не меняются: существующий watcher обновит панель после удаления JSON-файла.

## Детали реализации

- Tool принимает только `name`; profile/domain берутся из текущего Pi-контекста, как у `add_action`. Произвольные пути не принимаются.
- Имя нормализуется теми же trim + NFC + lowercase правилами и разрешается в ID существующей Action.
- При успешном вызове удаляется только `<current-domain>/actions/<id>.json`. Логи, другие Actions и каталоги сохраняются.
- До удаления проверяются реальные каталоги, regular-file запись, JSON, совпадение ID и имя. Symlink, повреждённая запись, неверное/пустое имя и отсутствующая Action завершаются ошибкой без изменения файлов.
- Удаление не запускает и не останавливает команды; если Action сейчас выполняется, запись удалить можно, но уже запущенный процесс и его лог продолжают жить независимо.
- Операция синхронная, возвращает ясный результат успеха/ошибки. Подтверждение в UI не показывается.

## Критерии приёмки

- [x] `remove_action` сразу удаляет только запись соответствующего имени в активном folder-domain.
- [x] Неверное/пустое имя и отсутствующая запись дают ошибку без создания каталогов и мутаций.
- [x] Повреждённая запись и несовпадение имени/ID отклоняются fail-closed встроенной валидацией `readActionRecord`.
- [x] Логи, соседние Actions и другие профили/domains остаются нетронутыми.
- [x] Tool не запускает и не останавливает команды.
- [x] Pi targeted Automata tests: 17/17; `pnpm exec tsc --noEmit` прошёл.
- [x] Полный Pi suite запускался; два теста familiar упали (blocking checkpoint: 0 вместо 1; commit_memory: false вместо true). Изолированный familiar suite подтвердил независимые падения (checkpoint 0 вместо 1; memory count 3 вместо 1); причины не исследовались.
- [x] `CONTEXT.md`, новая спецификация и изменённые Pi-файлы прошли scoped `git diff --check`; newline/whitespace и typecheck проверены. Коммит не создавался.
