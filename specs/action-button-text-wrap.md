# Перенос текста Action-кнопок

## Контекст

В секции Actions правой панели название кнопки выводится одной строкой и обрезается `…` (`ansi.Truncate` в `internal/ai-knowledge/ui/render.go`). Клик привязан к одной строке на кнопку: `KnowledgePanel.View` считает `sectionLines[0] + index + 1`, то есть предполагает ровно одну строку на действие. Длинное название нельзя прочитать целиком.

## Цель

Название Action-кнопки (в том числе `● name · running`) переносится на несколько строк по ширине панели, а клик по любой строке переноса работает так же, как по кнопке: открывает подтверждение или останавливает запуск.

## Что изменится

1. `internal/ai-knowledge/ui/render.go` — перенос строк кнопки и экспортируемая функция высот кнопок.
2. `internal/ai-knowledge/ui/render_test.go` — тесты переноса и высот.
3. `internal/ui/knowledge_panel.go` — карта кликов `actionRows` охватывает все строки каждой кнопки.
4. `internal/ui/knowledge_panel_test.go` — тест кликов по строкам переноса.
5. `CONTEXT.md` — запись о поведении.

## Детали реализации

1. В `render.go` ввести внутреннюю `actionLines(width int, action actions.Action, running bool) []string`: через существующий `wrapPrefixed` с префиксом `  ↗ ` для обычной кнопки и `  ● ` для работающей, текст `name` или `name · running`; продолжение строки выравнивается под началом названия (висячий отступ).
2. `ContentWithActions` выводит все строки `actionLines`, стиль (`item` или `running`) применяется к каждой строке.
3. Экспортировать `ActionRowHeights(width int, actionList []actions.Action, runningActionIDs map[string]bool) []int`: число строк каждой кнопки, считается через ту же `actionLines`, чтобы рендер и хитбоксы не расходились (DRY).
4. В `KnowledgePanel.View` вместо `index + 1` накапливать смещение по `ActionRowHeights` и записывать в `actionRows` каждую строку кнопки (с учётом `scrollOffset` и `bodyHeight`).
5. Поведение клика, подтверждения и остановки не меняется; пустое состояние `(no actions)` и свёрнутая секция остаются прежними.

## Критерии приёмки

- [x] Длинное название кнопки переносится на несколько строк, ни одна строка не шире панели, текст не обрезается.
- [x] Продолжение строки выровнено под началом названия.
- [x] Работающая кнопка тоже переносится, подсветка применяется ко всем её строкам.
- [x] Клик по любой строке переноса открывает подтверждение (или останавливает работающий запуск).
- [x] Соседние кнопки после переноса сохраняют корректные хитбоксы.
- [x] `gofmt`, `go vet`, `golangci-lint`, `go test ./...` и race-тесты проходят; коммит не создаётся.
- [ ] После пересборки и перезапуска у Ани длинное название переносится.
