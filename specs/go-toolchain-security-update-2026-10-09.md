# Обновление Go toolchain для security gate

## Контекст

`go.mod` закрепляет `go 1.26.6`, а CI получает версию Go из `go.mod`. Обновлённая база govulncheck сообщает о десяти достижимых уязвимостях стандартной библиотеки для Go 1.26.6; исправленная версия указана как Go 1.26.9. README также называет 1.26.6 минимальной версией. Скан отдельно сообщает о package/module findings, которые проектный код, по его оценке, не вызывает.

## Цель

Обновить минимальный Go toolchain до 1.26.9 и проверить, что обязательный security scan больше не находит достижимых уязвимостей. Не обновлять Warp, Portalis или другие зависимости и не подавлять результаты govulncheck.

## Что изменится

1. `go.mod` — установить минимальную Go-версию 1.26.9.
2. `README.md` — обновить указанное минимальное требование.
3. `CONTEXT.md` — записать подтверждённое решение и результаты gate.
4. Эта спецификация — зафиксировать критерии и итог проверки.

`setup-go` в `.github/workflows/ci.yml` уже использует `go-version-file: go.mod`; менять workflow не планируется. Версии модулей и `go.sum` не менять.

## Детали реализации

1. Проверить Go 1.26.9 на доступность и использовать его для всех локальных проверок.
2. Изменить только директиву `go` в `go.mod` и минимальную версию Go в README.
3. Запустить `go mod verify`, форматирование, vet, линтер, govulncheck, полный Go/E2E-набор, race suite и Linux/macOS cross-build.
4. Проверить полный govulncheck output: все reachable findings должны исчезнуть; оставшиеся невызываемые package/module findings перечислить отдельно и не скрывать.
5. Провести обновление через pull request; не обходить обязательный security gate и не обновлять `main`, пока GitHub `quality` не пройдёт на точном SHA PR.

## Критерии приёмки

- [x] `go.mod` и README требуют Go 1.26.9 или новее в поддерживаемой линии 1.26.x.
- [x] `go.sum`, версии Warp/Portalis и остальные зависимости не изменены.
- [x] `govulncheck` на Go 1.26.9 сообщает ноль достижимых уязвимостей и ноль уязвимостей в импортируемых пакетах. Остался один module-only finding `GO-2026-5024`: Windows API `golang.org/x/sys@v0.38.0` (`NewNTUnicodeString`), проект его не вызывает; исправлено в `x/sys@v0.44.0`.
- [x] Полный локальный quality gate проходит на Go 1.26.9: module verify, форматирование, vet, lint (0), govulncheck, полный Go/E2E, отдельный E2E, race suite и Linux/macOS cross-build.
- [x] `git diff --check` проходит; `go.sum` и dependency versions не менялись.

## Текущий статус публикации
