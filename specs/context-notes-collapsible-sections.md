# Сворачиваемые заметки Content

## Контекст

Content-панель уже показывает notes с Markdown-секциями, но длинный контент занимает весь экран. Каждая заметка должна быть самостоятельной сворачиваемой секцией; внутренние Markdown-секции сохраняют порядок и отображаются внутри раскрытой заметки без дополнительного управления.

## Цель

Добавить в ContextPanel по одной визуально выделенной сворачиваемой секции на заметку с отступами, состоянием collapsed-by-default и переключением раскрытия мышью и клавиатурой.

## Поведение

- Единица сворачивания — заметка, а не отдельная `section` из `notes.json`.
- Каждая заметка начинается строкой-заголовком с маркером `▸` в свернутом состоянии и `▾` в раскрытом.
- Внутренние секции раскрытой заметки выводятся в исходном порядке как Markdown-заголовки и содержимое; собственных маркеров и состояний раскрытия у них нет.
- Все заметки свернуты при первом отображении домена.
- Клик левой кнопкой по строке заголовка заметки переключает её состояние.
- При фокусе Content-панели клавиши `Enter` и `Space` переключают активную заметку.
- `↑`/`↓` перемещают активную заметку; `←` сворачивает её, `→` раскрывает её.
- При смене домена состояние заметок сбрасывается, все заметки снова свернуты.
- Состояние не записывается в notes.json и не переносится между доменами или перезапусками.
- Legacy notes без sections остаются читаемыми; каждая такая заметка также отображается одной свернутой секцией.

## Дизайн

- Заголовок заметки имеет отступ 1 пробел, маркер `▸`/`▾` и нейтральный серый текст.
- Содержимое раскрытой заметки получает компактный префикс ` │ `; вертикальная линия находится под маркером, существующее Markdown-форматирование сохраняется.
- Заголовок каждой внутренней секции выводится как Markdown-заголовок внутри раскрытого блока.
- Раскрытый блок получает визуальную вертикальную направляющую `│` слева от контента.
- Пустые заметки и секции показывают только доступный заголовок и раскрываются без ошибки.
- Вложенных интерактивных секций нет: одна заметка — одна строка управления.

## Что изменится

1. `internal/ui/context_panel.go` — состояние заметок, обработка событий, отрисовка и сброс при смене домена.
2. `internal/ui/markdown.go` — возможность задавать базовый отступ и направляющую раскрытого блока.
3. `internal/ui/context_panel_test.go` — поведение мыши, клавиатуры, сброс состояния и legacy-секция.
4. `internal/ui/markdown_test.go` — регрессия отступов и ширины.
5. `CONTEXT.md` — запись проблемы и решения после завершения.

## Критерии приёмки

- [x] Все заметки свернуты по умолчанию.
- [x] Заголовки заметок показывают `▸`/`▾` и имеют заметные отступы.
- [x] Мышь переключает заметку по клику на её заголовок.
- [x] `Enter`/`Space`, `←`/`→` и `↑`/`↓` управляют заметками.
- [x] Раскрытый Markdown-контент имеет дополнительный отступ и направляющую.
- [x] Внутренние секции отображаются в одной раскрытой заметке без вложенного управления.
- [x] Смена домена сбрасывает состояние заметок.
- [x] Legacy notes продолжают отображаться и также сворачиваются.
- [x] Watcher notes и существующая прокрутка продолжают работать.
- [x] `gofmt`, `go vet ./...`, `go test ./...` и `go build -o automata .` проходят.
- [x] Коммит не создан.

Реализовано 2026-09-06. Content-панель получила collapsed-by-default заметки: каждая заметка является одной секцией управления, а её внутренние Markdown-секции раскрываются единым блоком с отступами и направляющей.
