# Архивация папок

## Контекст
Пользователь хочет "архивировать" папки. Визуально это выглядит как длинная разделительная линия: элементы над линией — активные, папки под линией — заархивированные.

## Цель
Реализовать архивную зону для папок. Архивация — это метка папки, которая влияет на отображение и позиционирование относительно разделительной линии.

## Поведение

### Визуально
- Внутри каждой раскрытой папки, имеющей архивные подпапки, рисуется горизонтальная линия `────────────` перед архивными папками.
- Линия рисуется и в корне, если есть архивные корневые папки.
- Линия занимает всю ширину контентной области (с учётом отступа папки и скроллбара).
- Архивные папки отображаются серым/приглушённым цветом.
- Чаты и терминалы архивировать нельзя.

### Архивация / разархивация
- **Drag & drop**: перетащить **папку** ниже линии — архивировать; выше линии — разархивировать. Чаты и терминалы не меняют архивный статус.
- **Контекстное меню**: у папок пункт `Archive` / `Unarchive`. У чатов и терминалов пункта нет.
- При создании новой папки она появляется над линией (не архивная).

### State persistence
- `Item` и `StateItem` получают поле `Archived bool`.
- При сохранении/загрузке состояние архивации сохраняется.

### Сортировка
- Архивные папки всегда находятся после всех не-архивных элементов (папок, чатов, терминалов) внутри родительской папки или в корне.
- Чаты и терминалы сохраняют свой порядок в верхней (не-архивной) части.

## Реализация

### Модель
1. `internal/tree/model.go`:
   - `Item.Archived bool`
   - `toggleArchive(item *Item)` — только для папок.
   - При drag архивный статус меняется только для папок.

### Сериализация
2. `internal/tree/state.go`:
   - `StateItem.Archived bool`
   - `toStateItems` / `fromStateItems` сохраняют/восстанавливают поле.

### Рендеринг
3. `internal/tree/render.go`:
   - Добавить стиль `archivedStyle` (серый).
   - Рисовать линию перед первой архивной папкой в корне и внутри каждой раскрытой папки.
   - В `renderItemLine` применять `archivedStyle` к архивным папкам.

### UI
4. `internal/tree/input.go`:
   - В контекстном меню папок: `Archive` / `Unarchive`.

## Критерии приёмки
- [ ] Архивная линия рисуется в папках и в корне с архивными папками.
- [ ] Архивные папки серые.
- [ ] Drag папки через линию меняет её архивный статус.
- [ ] Чаты и терминалы нельзя архивировать.
- [ ] Контекстное меню папки имеет Archive/Unarchive.
- [ ] Состояние сохраняется между запусками.
- [ ] `go test ./...`, `go vet ./...`, `go build` проходят.
