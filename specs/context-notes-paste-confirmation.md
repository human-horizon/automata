# Подтверждение вставки заметок и отступы toolbar

## Контекст

В Content-панели Automata кнопки `Paste +` и `Paste replace` сразу читают системный буфер и изменяют заметки. Для защиты от случайного нажатия перед обеими операциями нужно показывать подтверждение. Строка кнопок сейчас находится сразу под вкладками, поэтому ей нужны пустые строки сверху и снизу.

## Цель

Добавить подтверждение перед чтением буфера для `Paste +` и `Paste replace`, не изменяя поведение `Copy`, и расположить toolbar с одной пустой строкой сверху и снизу.

## Что изменится

1. `internal/ui/context_panel.go` — состояние и обработка модального подтверждения, запуск вставки только после подтверждения, overlay модального окна, новые координаты toolbar и заметок.
2. `internal/ui/context_panel_test.go` — проверки подтверждения, отмены, отсутствия чтения буфера до подтверждения и вертикальных отступов.
3. `specs/context-notes-paste-confirmation.md` — спецификация и результат реализации.
4. `CONTEXT.md` — запись проблемы и решения после завершения.

## Детали реализации

1. Нажатие `Paste +` открывает модальное окно с вопросом добавления заметок из буфера и кнопками `Yes`/`No`.
2. Нажатие `Paste replace` открывает модальное окно с вопросом замены текущих заметок и кнопками `Yes`/`No`.
3. Подтверждение выполняется кнопкой `Yes` или клавишей `Y`; после него запускается существующая асинхронная команда чтения clipboard.
4. Отмена выполняется кнопкой `No`, клавишей `N`, `Esc`, крестиком или кликом вне модального окна. До подтверждения буфер не читается, а файл заметок не изменяется.
5. Пока подтверждение открыто, события не передаются вкладкам, заметкам и toolbar. `Copy` продолжает работать без подтверждения.
6. В Content-вкладке сохраняется строка вкладок сверху, затем добавляются: одна пустая строка, toolbar, одна пустая строка, область заметок. Hit-testing обновляется под новые координаты.
7. При малой высоте панель показывает только те строки, которые помещаются, без выхода за заданную высоту.

## Критерии приёмки

- [x] `Paste +` открывает подтверждение и не читает буфер до `Yes`.
- [x] `Paste replace` открывает подтверждение и не читает буфер до `Yes`.
- [x] `Yes` продолжает соответствующую операцию; `No`, `N`, `Esc`, крестик и внешний клик отменяют её.
- [x] Отмена не меняет `notes.json`.
- [x] `Copy` по-прежнему выполняется без подтверждения.
- [x] Между вкладками и toolbar есть одна пустая строка, а между toolbar и заметками — одна пустая строка.
- [x] Toolbar и заметки попадают под корректные координаты мыши после добавления отступов.
- [x] Адресные тесты, `go vet ./...`, `go test ./...`, `go build`, `gofmt` и `git diff --check` проходят.
- [x] Коммит не создан.

## Результат

Реализовано в `internal/ui/context_panel.go`: вставка теперь запускается только после подтверждения, а модальное окно блокирует фоновые действия до отмены или подтверждения. Добавлены тесты в `internal/ui/context_panel_test.go`; финальные проверки отмечаются после полного прогона.
