# Логирование Actualize — отменено

## Решение пользователя
По запросу Ани временное логирование Actualize и UI-ссылка LOG удаляются. Отдельный semantic-review вызов также удаляется; остаются строгая JSON/schema-валидация, приватный backup/Undo, проверка исходного fingerprint и атомарный commit.

## История
Предыдущая реализация логировала фактический вывод CLI в приватный временный файл и показывала file URI ссылку в toolbar; временная версия была установлена в Automata. Source-код логирования и ссылок удалён по решению пользователя. Установленный binary требует отдельной пересборки, чтобы убрать UI-функцию.

## Ограничение
Без отдельной semantic-review модельный ответ может пройти технические проверки и при этом потерять исходные факты. В таком случае Undo восстанавливает исходные bytes, если Notes после commit не менялись.

Статус: отменена; runtime-код логирования и LOG UI не должны оставаться.
