# Клавиатурная навигация и сортировка верхнего уровня

## Контекст

Сейчас Automata в основном управляется мышью. Дерево умеет выбирать элементы с клавиатуры, но нет общего управления фокусом между деревом, рабочей панелью и правой панелью знаний. В заголовке дерева есть кнопка создания, но нет отдельного меню корневого уровня для сортировки. Пользователю также нужна встроенная справка по навигации.

Клавиши Pi и zellij нельзя перехватывать в чате или терминале, кроме глобального `Ctrl+C`, который всегда завершает Automata. Порядок элементов дерева уже сохраняется в `state.json`, поэтому отдельный параметр сортировки не нужен.

## Цель

Добавить безопасную клавиатурную навигацию между панелями, сделать все операции дерева достижимыми через клавиатурное контекстное меню, добавить меню `⋮` корневого уровня с сортировкой по имени и типу, а также справку по клавишам.

## Статус

Реализовано и проверено.

## Что изменится

1. `internal/tree/input.go` — навигация, открытие контекстных меню и help с клавиатуры.
2. `internal/tree/model.go` — сортировка корневых элементов по имени и типу, root-меню.
3. `internal/tree/render.go` и `internal/tree/elements.go` — кнопка `⋮`, кнопка Help внизу дерева и overlay справки.
4. `internal/tree/state.go` — сохранение порядка через существующий `SaveState` без нового формата.
5. `internal/ui/container.go` — управление фокусом вложенных панелей.
6. `main.go`, `main_overlay.go` — безопасный цикл фокуса и корневые Help/Settings overlays.
7. Unit/integration/E2E-тесты клавиатуры, сортировки, сохранения порядка, root overlays и Ctrl+C.

## Детали реализации

### 1. Фокус и клавиши

Фокус переключается только функциональными клавишами, не использующими Ctrl/Alt и не изменяющими ввод Pi:

- `F5` — предыдущий фокус.
- `F7` — следующий фокус.
- `F6` — вернуть фокус дереву (сохраняет существующее поведение Automata).
- Порядок фокуса: дерево → активный чат/терминал или контекст папки → правая панель знаний в режиме чата → дерево.
- `F1` — открыть/закрыть справку.
- `F10` — открыть контекстное меню выбранного элемента; если элемент не выбран — открыть root-меню.
- `F8` сохраняет существующее назначение переключения мыши.
- `Ctrl`, `Alt`, `Tab` и `Shift+Tab` не используются для переключения фокуса и передаются активной панели; в дереве навигация выполняется стрелками.

При фокусе дерева:

- `↑/↓` — выбрать предыдущий/следующий видимый элемент.
- `Home/End` — перейти к первому/последнему видимому элементу.
- `PageUp/PageDown` — переместиться на высоту видимой области.
- `←` на раскрытой папке — свернуть её; иначе выбрать родительскую папку.
- `→` на свернутой папке — раскрыть её; на раскрытой папке — выбрать первого ребёнка.
- `Enter` на папке — раскрыть/свернуть; на чате или терминале — открыть его.
- `F2` — переименовать выбранный элемент.
- `F10` — открыть меню действий. Навигация внутри меню выполняется стрелками, `Enter` запускает действие, `Esc` закрывает меню.

При фокусе чата/терминала все остальные клавиши, кроме глобального `Ctrl+C`, включая `Tab`, `Ctrl` и `Alt`, передаются Pi или shell без изменений.

### 2. Root-меню

В заголовке дерева добавляется кнопка `⋮`. Нажатие мышью или `F10` без выбранного элемента открывает меню верхнего уровня. В нём доступны создание папки/чата/терминала и сортировка:

- `Sort by name` — активные корневые элементы сортируются по имени без учёта регистра; архивные папки остаются в архивной группе внизу.
- `Sort by type` — активные корневые элементы группируются как папки, чаты, терминалы; внутри каждой группы сортируются по имени без учёта регистра; архивные папки остаются в архивной группе.

Сортируются только элементы `root`; дети папок не изменяются. Выбранный объект сохраняется по указателю/ID, session ID, `BoundPath`, активные процессы и данные сессий не меняются. После сортировки вызываются `rebuildFlat` и существующий `autoSave`, поэтому порядок переживает перезапуск.

Существующий пункт сортировки детей папки сохраняется и использует сортировку по имени.

### 3. Help

В нижней части левой панели добавляется кнопка `? Help`. Она открывает overlay со справкой на русском языке на корневом viewport всей Automata, а не внутри левой панели:

- как переключать фокус (`F5`/`F7`) и возвращаться к дереву (`F6`);
- как перемещаться по дереву;
- как открыть меню (`F10`), переименовать (`F2`) и открыть help (`F1`);
- какие клавиши не перехватываются в Pi/zellij.

Help открывается мышью или `F1`, закрывается `Esc`, `F1` или `Enter`. Пока help открыт, клавиши чата не передаются.

## Критерии приёмки

- [x] `F5`/`F7` циклически переключают фокус между доступными панелями, а `F6` возвращает фокус дереву.
- [x] В чате и терминале `Ctrl` (кроме `Ctrl+C`), `Alt`, `Tab`, `Shift+Tab` и обычный ввод не перехватываются деревом или глобальным Warp-обработчиком.
- [x] `Ctrl+C` завершает Automata из дерева, чата, терминала и любого overlay.
- [x] Стрелки, `Home/End`, `PageUp/PageDown`, `Enter`, `F2` и `F10` управляют деревом без мыши.
- [x] Контекстные меню полностью работают с клавиатуры.
- [x] В заголовке дерева отображается кликабельное меню `⋮`.
- [x] Root-меню сортирует только верхний уровень по имени и типу.
- [x] Сортировка сохраняет выделенный объект, не меняет детей, ID, данные сессий и `BoundPath`.
- [x] Порядок после сортировки сохраняется в `state.json` и восстанавливается после загрузки.
- [x] Внизу слева отображается кнопка Help, а `F1` открывает ту же справку на полном viewport Automata.
- [x] Settings открывается на полном viewport Automata, а выбор темы применяется live и сохраняется.
- [x] Справка объясняет карту клавиш и ограничения Pi/zellij.
- [x] Добавлены unit/integration/E2E-тесты; проходят `gofmt`, `go vet ./...`, `go test ./... -count=1 -p 1` и `go build -o automata .`.
