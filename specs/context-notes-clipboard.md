# Копирование и вставка заметок в Content

## Контекст

Content-панель Automata показывает все заметки текущего домена, но не позволяет перенести их в другой домен через системный буфер обмена. Нужны отдельные действия вставки для добавления заметок к существующим и полной замены существующих заметок.

## Цель

Добавить в Content-панель три кнопки: `Copy`, `Paste +` и `Paste replace`. Копирование переносит все заметки текущего домена с заголовками и секциями, а вставка добавляет или заменяет массив заметок текущего домена.

## Что изменится

1. `internal/ai-knowledge/memory/reader.go` — добавить безопасную запись массива заметок в канонический `notes.json`.
2. `internal/ai-knowledge/memory/reader_test.go` — проверить сериализацию и запись заметок.
3. `internal/ui/clipboard.go` — определить адаптер системного буфера и production-реализацию через поддерживаемую clipboard-библиотеку.
4. `internal/ui/context_panel.go` — добавить кнопки, hit-testing, асинхронные операции буфера, JSON-разбор и операции add/replace.
5. `internal/ui/context_panel_test.go` — проверить копирование, добавление, замену, ошибки и координаты кнопок.
6. `go.mod`/`go.sum` — добавить прямую зависимость clipboard-адаптера при необходимости.
7. `CONTEXT.md` — записать проблему и решение после завершения.

## Детали реализации

1. Копирование берёт **все** `data.Notes` текущего домена и сериализует их как JSON-массив, совместимый с `notes.json`. Формат сохраняет `title`, `sections`, а также legacy-поле `notes`, если оно присутствует.
2. Вставка читает JSON-массив из системного буфера и валидирует его до любых изменений на диске. Некорректный JSON, JSON не-массива или ошибка чтения буфера не изменяют `notes.json`.
3. `Paste +` записывает `existingNotes + pastedNotes`.
4. `Paste replace` записывает только `pastedNotes`.
5. Запись выполняется через временный файл в том же домене и атомарную замену `notes.json`; каталог домена создаётся при необходимости. После успешной записи панель перечитывает данные, а существующий watcher продолжает работать.
6. В Content-панели появляется отдельная строка кнопок под вкладками: `Copy`, `Paste +`, `Paste replace`. Кнопки обрабатываются только на Content-вкладке и только по левому клику. Нажатие не раскрывает и не меняет активную заметку.
7. Операции буфера выполняются через `tea.Cmd`, чтобы чтение/запись системного буфера не блокировали UI. После действия панель показывает краткий статус успеха или ошибки рядом с кнопками; содержимое заметок в статус не попадает.
8. Системный буфер изолируется интерфейсом. Тесты используют in-memory реализацию этого интерфейса, без обращения к ОС и внешним clipboard-командам.
9. Если домен не выбран, кнопки не выполняют запись; копирование разрешено только для текущего домена. Пустой массив из буфера допустим: `Paste +` сохраняет существующие заметки, `Paste replace` очищает их.

## Критерии приёмки

- [x] Content-панель показывает отдельные кнопки `Copy`, `Paste +` и `Paste replace`.
- [x] `Copy` помещает в буфер все заметки текущего домена и сохраняет структуру секций.
- [x] `Paste +` добавляет заметки из буфера после существующих, не теряя исходные.
- [x] `Paste replace` заменяет все текущие заметки содержимым буфера.
- [x] Некорректный буфер не изменяет `notes.json` и показывает ошибку.
- [x] Запись заметок атомарна, а обновлённые данные появляются в панели без перезапуска.
- [x] Legacy-заметки и пустой массив обрабатываются без паники.
- [x] Клики по кнопкам не переключают и не раскрывают заметки.
- [x] `gofmt`, адресные тесты, `go vet ./...`, `go test ./...`, `go build` и `git diff --check` проходят.
- [x] Коммит не создан.

## Результат

Реализовано 2026-09-10. В Content-панели появились отдельные кнопки для копирования, добавления и перезаписи заметок. Clipboard работает через системный адаптер, а тесты используют изолированный in-memory буфер.
