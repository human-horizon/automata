# Спецификация ручных тестов — Automata TUI

## Назначение
Проверка функциональности дерева чатов/папок и встроенного терминала в Automata.

## Окружение
- Терминал: 80×24 (фиксированный размер для детерминированности)
- Запуск: `go run .` из корня automata
- Выход: `q` или `Ctrl+C`

---

## Тест-кейсы

### T1: Запуск и отображение
**Шаги:**
1. Запустить приложение
2. Дождаться отрисовки

**Ожидаемый результат:**
- Дерево слева (≈24 колонки), пустая панель справа
- В дереве 3 элемента: `- 📂 Сегодня`, `💬 Общие вопросы`, `- 📂 Проекты`

### T2: Навигация клавиатурой
**Шаги:**
1. Нажать `↓` дважды
2. Нажать `↑`

**Ожидаемый результат:**
- После двух `↓`: выделен «Общие вопросы»
- После `↑`: выделен «Сегодня»

### T3: Свернуть/развернуть папку
**Шаги:**
1. Убедиться, что «Сегодня» выделена
2. Нажать `Enter`
3. Нажать `Enter` ещё раз

**Ожидаемый результат:**
- После шага 2: иконка меняется на `+ 📁`, дочерние элементы скрываются
- После шага 3: иконка `- 📂`, элементы видны

### T4: Клик на [+] — меню создания
**Шаги:**
1. Свернуть папку «Проекты» (Enter)
2. Кликнуть на `+` рядом с «Проекты»

**Ожидаемый результат:**
- Появляется меню: `New Folder`, `New Chat`
- Клик по пункту создаёт элемент внутри папки

### T5: Клик на пустое место — меню создания в корне
**Шаги:**
1. Кликнуть на пустое место ниже всех элементов дерева

**Ожидаемый результат:**
- Появляется меню: `New Folder`, `New Chat`
- Создаёт элемент в корне дерева

### T6: Контекстное меню (правый клик)
**Шаги:**
1. Правый клик на папке

**Ожидаемый результат:**
- Появляется меню: New Folder, New Chat, Rename, Delete
- Клик по пункту выполняет действие

### T7: Создание через клавиатуру
**Шаги:**
1. Выделить папку
2. Нажать `a` (New Folder) или `c` (New Chat)
3. Ввести имя, Enter

**Ожидаемый результат:**
- Элемент создан внутри выбранной папки

### T7a: Создание через mouse (меню папки)
**Шаги:**
1. Свернуть папку (Enter на выделенной папке)
2. Кликнуть на `[+]` рядом с папкой
3. Кликнуть `New Chat` в меню
4. Ввести имя, Enter

**Ожидаемый результат:**
- Меню появляется рядом с папкой
- Чат создан внутри папки

### T7b: Создание через mouse (пустое место)
**Шаги:**
1. Кликнуть на пустое место ниже всех элементов
2. Кликнуть `New Chat` в меню
3. Ввести имя, Enter

**Ожидаемый результат:**
- Чат создан в корне дерева

### T8: Переименование
**Шаги:**
1. Выделить элемент
2. Нажать `r`
3. Ввести новое имя
4. Нажать `Enter`

**Ожидаемый результат:**
- Элемент переименован

### T9: Удаление
**Шаги:**
1. Выделить элемент
2. Нажать `d`
3. В модальном окне подтверждения нажать `Space`, `Enter` или `y` для подтверждения, либо `Esc` / `n` для отмены

**Ожидаемый результат:**
- Появляется модальное окно подтверждения с текстом "Delete chat/folder \"X\"?" и кнопками `[Del]` / `[Esc]`
- При подтверждении элемент удалён
- При отмене элемент остаётся

### T9a: Drag модального окна
**Шаги:**
1. Открыть любое модальное окно (создание, переименование или удаление)
2. Нажать левую кнопку мыши на заголовке/содержимом модального окна (не на кнопках)
3. Переместить мышь и отпустить кнопку

**Ожидаемый результат:**
- Модальное окно перемещается вслед за курсором
- После отпускания кнопки окно остаётся на новом месте

### T9b: Drag & drop элемента дерева
**Шаги:**
1. Навести мышь на элемент (папку или чат)
2. Зажать левую кнопку мыши на строке элемента (не на `⋮`)
3. Переместить мышь на другой элемент
4. Отпустить кнопку

**Ожидаемый результат:**
- Элемент перемещается в новое место
- Если target — папка: элемент внутри папки
- Если target — чат: элемент после чата

### T9c: Контекстное меню через `⋮`
**Шаги:**
1. Навести мышь на элемент
2. Кликнуть на `⋮`

**Ожидаемый результат:**
- Появляется контекстное меню с действиями
- Для папок: New Folder, New Chat, Rename, Delete
- Для чатов: Rename, Delete

### T10: Открытие чата и терминал
**Шаги:**
1. Выделить чат «Общие вопросы»
2. Нажать `Enter`
3. Подождать 1 секунду

**Ожидаемый результат:**
- Фокус переходит на правую панель
- В правой панели появляется терминал с bash/zsh prompt
- При `PI_CMD=pi` запускается `pi --session <id>`
- Если `PI_CMD` не задан, используется `term.DefaultShell()`, который предпочитает абсолютные пути (`/bin/bash`, `/bin/zsh`, `/bin/sh`) для работы в окружениях с минимальным `PATH`

### T10a: SessionID корневого чата
**Шаги (после T10):**
1. Ввести `echo "$AUTOMATA_SESSION_ID"`
2. Нажать `Enter`

**Ожидаемый результат:**
- Вывод содержит slug-путь cwd + slug-имя чата, разделённые точками
- Пример: `users.a.space.projects.humanhorizon.automata.obschie-voprosy`

### T10b: SessionID чата в папке
**Шаги:**
1. Создать папку, создать в ней чат
2. Открыть чат
3. Ввести `echo "$AUTOMATA_SESSION_ID"`

**Ожидаемый результат:**
- Вывод содержит slug-путь cwd + slug-папки + slug-имя чата
- Пример: `users.a.space.projects.humanhorizon.automata.proekty.mychat`

### T10c: Уникальность sessionID
**Шаги:**
1. Создать чат «My Chat» в папке «Сегодня»
2. Создать чат «My Chat» в папке «Проекты»
3. Открыть каждый чат и проверить `$AUTOMATA_SESSION_ID`

**Ожидаемый результат:**
- Два разных sessionID: `...segodnya.mychat` и `...proekty.mychat`

### T11: Ввод команд в терминал
**Шаги (после T10):**
1. Ввести `ls`
2. Нажать `Enter`

**Ожидаемый результат:**
- Команда отображается после prompt
- Вывод `ls` появляется в терминале

### T12: Скролл дерева
**Шаги:**
1. Создать 20+ элементов
2. Прокрутить колёсиком или клавишами

**Ожидаемый результат:**
- Список прокручивается
- Скроллбар справа движется

## Переменные окружения

| Переменная | Описание |
|-----------|----------|
| `PI_CMD` | Команда для запуска pi (default: login shell из `term.DefaultShell()`) |
| `F6` | Вернуть фокус из правой панели обратно в дерево |

---

## Ручное тестирование через cue-tty
Для автоматизированного "ручного" прогона сценариев используется `go run ./e2e/manual`. Скрипт проверяет:
- отображение дерева при старте;
- навигацию ↑↓ и сворачивание/развёртывание папок Enter;
- создание папки в корне через меню пустого пространства;
- создание чатов внутри папки через `c`;
- открытие чата и запуск терминала;
- корректность `$AUTOMATA_SESSION_ID` для `notes` (`...work.notes`) и `tasks` (`...work.tasks`);
- возврат фокуса в дерево по `F6`.
